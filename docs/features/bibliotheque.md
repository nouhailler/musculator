# Bibliothèque d'exercices

## Description
Le catalogue complet : 152 exercices, chacun avec sa fiche (départ, mouvement, muscle ciblé,
surcharge à éviter, conseils, erreurs fréquentes, variantes) et une **démonstration animée**.

## Objectif
Savoir exécuter un mouvement correctement, et comprendre ce qu'il travaille.

## Prérequis
Aucun.

## Comment l'utiliser
1. Onglet *Exos*.
2. Cherchez par nom, ou filtrez par niveau et matériel.
3. Les exercices sont regroupés par schéma de mouvement (poussée, fente, hinge, abduction…).
4. Touchez un exercice pour ouvrir sa fiche.

## Options
- **Mollets & avancés** — fait apparaître les exercices optionnels, masqués par défaut dans
  tout le catalogue.
- **Faire cet exercice maintenant** — lance une [séance d'un seul exercice](seance-guidee.md).

## Paramètres associés
Aucun.

## Données utilisées
**Lecture seule** : le catalogue embarqué. Rien n'est écrit — sauf si vous lancez l'exercice,
qui produit alors une séance.

## Résultat
Consultation. Les démos sont dessinées en SVG à partir de poses articulaires, pas des vidéos.

## Fonctionnement hors connexion
Identique. Rien n'est téléchargé : le catalogue et les démos font partie de l'application.

## Fonctionnement en ligne
Identique.

## Limites
- **Un mouvement dont le plan est perpendiculaire à l'écran ne peut pas être dessiné de
  profil.** La rétraction des omoplates montre sa conséquence visible (le coude qui recule,
  la poitrine qui s'ouvre) plutôt que le mouvement lui-même.
- **Un maintien n'a pas de tempo** : les démos d'étirement et de gainage bougent de quelques
  degrés seulement.
- **Une rotation continue ne peut pas boucler** : les cercles de bras montrent l'amplitude
  balayée, pas un tour complet.
- Les démos sont schématiques : ce sont des repères, pas une démonstration filmée.
- Le filtre *Matériel* compare littéralement au vocabulaire du catalogue
  (Sans matériel · Haltères · Élastique · Salle · Maison).
