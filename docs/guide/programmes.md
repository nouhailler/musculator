# Programmes

**Objectif** — choisir une séance à faire, ou en composer une.

**Accès** — onglet *Programmes*, ou menu ☰ → *Programmes*.

## Éléments de l'interface

- **Filtres** — *Durée*, *Niveau* et *Matériel*. Ils se combinent ; les trois valent
  « Toutes / Tous » par défaut.
- **Liste des programmes** — 12 programmes du catalogue, plus vos séances perso.
- **Créer une séance** — ouvre le [créateur](createur.md).
- **Importer un programme dicté** — ouvre [l'import](imports.md).

## Actions et résultats

| Action | Résultat |
|---|---|
| Toucher un programme | Ouvre le [détail du programme](detail-programme.md) |
| Changer un filtre | Restreint la liste immédiatement |
| *Créer une séance* | Ouvre le créateur |
| *Importer un programme dicté* | Ouvre l'écran d'import JSON |

## Cas particuliers

- **Plus aucun résultat** — les trois filtres se combinent ; élargissez-en un.
- **Séances perso** — enregistrées sur l'appareil, elles apparaissent dans la même liste et
  se comportent comme les programmes du catalogue.
- **Un programme du catalogue peut prescrire ses propres réglages** — une séance corrective
  peut demander moins de répétitions que la fiche de l'exercice. Le détail du programme
  affiche la valeur qui s'appliquera.

## Erreurs possibles

Aucune sur cet écran. Les erreurs d'import sont listées dans
[Codes et erreurs](../reference/errors.md).
