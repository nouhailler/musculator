# Le coach vocal ne parle pas

## Symptôme

La séance se déroule normalement mais rien n'est annoncé.

## Causes possibles

- Le coach a été **coupé** (haut-parleur pendant la séance, ou menu ☰).
- Le **volume** du téléphone est coupé, ou le mode silencieux est actif.
- **Aucune voix française n'est installée** sur le système.
- Le navigateur **n'expose pas la synthèse vocale**.
- **iOS attend une première interaction** de l'utilisateur avant d'autoriser la synthèse.
- La voix du système est **téléchargée à la demande** et vous êtes hors ligne.

## Diagnostic

1. Menu ☰ : la ligne indique-t-elle *Coach vocal activé* ou *coupé* ?
2. Montez le volume média et désactivez le mode silencieux.
3. Touchez un bouton de l'application, puis relancez une phase de séance.
4. Testez la synthèse vocale ailleurs (lecture à voix haute d'une page, accessibilité du
   téléphone) : si elle est muette partout, le problème est système.

## Solution

- **Réactivez** le coach : menu ☰ → *Coach vocal*, ou le haut-parleur pendant la séance.
- **Installez une voix française** : Android → Paramètres → Synthèse vocale → voix
  françaises. iOS → Réglages → Accessibilité → Contenu énoncé → Voix.
- **Connectez-vous une fois** au réseau pour que le système télécharge la voix, puis
  réessayez hors ligne.
- Sur navigateur de bureau, essayez Chrome ou Edge : tous n'ont pas de voix installée.

## Si le problème persiste

L'application **n'affiche aucune erreur** dans ce cas : un navigateur sans synthèse vocale
reste simplement silencieux, et la séance fonctionne normalement. Ce n'est pas une panne de
l'application mais une limite du système.

## Informations à fournir au support

Plateforme, navigateur, si la synthèse vocale fonctionne ailleurs sur l'appareil, et si le
coach a déjà parlé par le passé.
